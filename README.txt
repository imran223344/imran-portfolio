GitHub Pages:
1. Create/open your repository.
2. Upload all four files.
3. Make sure index.html is in the repository root.
4. Settings -> Pages -> Deploy from branch -> main -> /root.
5. Open the GitHub Pages URL.

No server/database is required. The website is static and mobile-friendly.
